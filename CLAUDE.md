# Immoradar-Prototyp

React + Vite Frontend-Prototyp mit Dummy-Daten (kein Backend, keine echte
Berechnungslogik). Live unter: https://eliaswuestenhoefer.github.io/immoradar-prototyp/

## Git-Workflow

- **Niemals automatisch pushen.**
- Wenn eine Änderung fertig und getestet ist: kurz zusammenfassen, was
  geändert wurde, und explizit fragen, ob committet und gepusht werden soll.
- Erst nach ausdrücklichem OK: `git add`, `git commit` mit sinnvoller
  Nachricht, `git push` auf `main`.
